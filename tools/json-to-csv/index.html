JSON to CSV Converter

Convert JSON files to CSV format instantly in your browser. No uploads, no servers — your data stays private.

How it works

  1. Drop your JSON file or click to browse
  2. Navigate to the data array if your JSON is nested
  3. Configure flattening and serialization options
  4. Download your CSV file

Everything runs in your browser. Your data never leaves your machine.

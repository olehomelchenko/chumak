# Keyboard Shortcuts

Quick reference for keyboard shortcuts available in Syto. Shortcuts are active when no dialog is open and you're not typing in an input field.

## Navigation

| Shortcut     | Action                    |
| ------------ | ------------------------- |
| `Arrow Up`   | Navigate to previous step |
| `Arrow Down` | Navigate to next step     |

## Actions

| Shortcut           | Action                          |
| ------------------ | ------------------------------- |
| `Ctrl+S` / `Cmd+S` | Download workflow as JSON       |
| `Delete`           | Remove the last step            |
| `Escape`           | Close dialog or clear selection |

## Data Import

| Shortcut           | Action                                |
| ------------------ | ------------------------------------- |
| `Ctrl+V` / `Cmd+V` | Paste tabular data from clipboard     |
| Drag & Drop        | Drop CSV files onto the app to import |

## Inside Dialogs

| Shortcut            | Action                      |
| ------------------- | --------------------------- |
| `Tab` / `Shift+Tab` | Move between form fields    |
| `Enter`             | Apply the current dialog    |
| `Escape`            | Cancel and close the dialog |

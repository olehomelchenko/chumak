# Що нового

Останні оновлення та нові можливості Syto.

## Багатомодельні пайплайни

Створюйте кілька моделей з одного джерела, кожна зі своїм пайплайном трансформацій. Моделі можуть залежати одна від одної через з'єднання та об'єднання з автоматичним відстеженням актуальності.

## Віконні функції

Додано підтримку віконних функцій: нумерація рядків, ранжування, lag/lead, заповнення вгору/вниз та інше. Обчислюйте значення на основі позиції рядка без згортання даних.

## Графіки EDA

Перемикайте панель розвідувального аналізу даних для перегляду boxplot-діаграм та гістограм для числових стовпців з можливістю виділення для інтерактивної фільтрації.

## Генерація синтетичних даних

Генеруйте тестові набори даних з реалістичними патернами безпосередньо у браузері. Корисно для прототипування пайплайнів або навчання концепціям роботи з даними.

## Комбінації клавіш

Навігація кроками за допомогою клавіш-стрілок, збереження робочих процесів через Ctrl+S та видалення кроків клавішею Delete. Дивіться сторінку Комбінацій клавіш для повного списку.

## Умовні стовпці

Створюйте нові стовпці з логікою if/then/else за допомогою трансформації Умовний стовпець — без необхідності знання синтаксису виразів.

## Підтримка JSON

Імпортуйте JSON-файли та масиви. Використовуйте функції `json_extract()` та `is_json()` для роботи з JSON-рядками у ваших даних.

## Операції з датами

Розбір дат з рядків, вилучення року/місяця/дня та обрізання до тижня/місяця/кварталу. Повна підтримка роботи з датами та часовими зонами.

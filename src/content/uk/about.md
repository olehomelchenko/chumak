# Syto

**Обробка даних у браузері** — очищуйте, трансформуйте та готуйте дані без встановлення програм.

Syto — це браузерний інструмент для роботи з табличними даними. Як Power Query, але працює будь-де — без встановлення, без акаунтів, дані не залишають ваш комп'ютер.

## Як це зроблено

Створено [Олегом Омельченко](https://www.linkedin.com/in/olehomelchenko/) за допомогою [Claude Code](https://claude.ai/claude-code) — трансформації даних надійні, а в UI можуть бути шорсткості.

# Початок роботи

Сито — це браузерний інструмент для очищення та трансформації табличних даних. Усе працює локально — ваші дані не залишають комп'ютер.

## Спробуйте без власних даних

Немає під рукою файлу? У порожньому стані виберіть один із вбудованих **демонстраційних наборів** (iris, cars, superstore, weather, airports, unemployment, S&P 500, stocks, barley, квартет Анскомба). Це зручний спосіб дослідити можливості Сито, перш ніж завантажувати власні дані.

## Основні поняття

### Джерела (Sources)

**Джерело** — це необроблені дані у тому вигляді, як їх імпортували. Кожне джерело зберігається у вашому браузері (IndexedDB) — нічого не надсилається на сервер. Створити джерело можна так:

- Перетягнувши файл CSV, JSON або Excel у вікно програми
- Вставивши табличні дані з електронної таблиці (`Ctrl/Cmd+V`)
- Вказавши URL (наприклад, посилання на CSV у мережі)
- Згенерувавши синтетичні дані (послідовності чисел/дат, випадкові числа, категорії)
- Обравши вбудований демонстраційний набір

Пізніше можна оновити дані джерела, не втрачаючи побудованих на ньому трансформацій — Сито зберігає резервну копію попередніх даних на один крок, якщо нові дані виявляться неправильними.

### Моделі (Models)

**Модель** — це трансформована версія джерела. Додавання кроків до джерела створює модель; моделі автоматично оновлюються, коли змінюються дані на вході.

З одного джерела можна побудувати багато моделей, а одна модель може слугувати входом для іншої (ланцюжок трансформацій). Коли змінюється вхідне джерело або модель, залежні моделі позначаються як застарілі та перераховуються на вимогу.

### Кроки (Steps)

**Крок** — це одна трансформація у пайплайні, що застосовується послідовно одна за одною. Більшість кроків доступні для редагування: натисніть на крок, щоб його редагувати; зміни поширюються вниз по ланцюжку.

Трансформації згруповані у три вкладки стрічки інструментів:

- **Рядки (Rows)** — фільтрація, сортування, видалення дублікатів, вирізання (slice), вибірка (sample), підняття рядка у заголовки
- **Стовпці (Columns)** — редагування стовпців (вибір/перейменування/видалення/упорядкування, операції за шаблоном), розділення (split), об'єднання (merge), похідний стовпець (derive), умовні вирази (conditional), match/extract (regex), індекс, перетворення значень (текст/дата/число/конвертація, заміна, заповнення пропусків), типи
- **Таблиця (Table)** — групування, віконні функції (lag, rank, running total, moving average), describe, pivot / unpivot, spread / unroll, join, append

## Типовий робочий процес

1. **Імпорт** — перетягніть файл, вставте з буфера обміну або виберіть демонстраційний набір.
2. **Дослідження** — увімкніть **панель EDA** (іконка графіка), щоб побачити розподіли стовпців, зведену статистику та рекомендації двовимірних графіків. Клікніть на лічильник пропусків або помилок, щоб одразу відфільтрувати їх. Тонкі смужки на заголовках стовпців показують відсоток помилок і пропусків.
3. **Трансформація** — виберіть трансформацію зі стрічки або натисніть на заголовок стовпця чи комірку, щоб викликати її в контексті.
4. **Ітерація** — скасовуйте зміни (`Ctrl/Cmd+Z`), змінюйте порядок, редагуйте чи видаляйте кроки. Кешування кроків пайплайна перераховує лише від точки зміни.
5. **Експорт** — завантажте очищені дані як CSV чи JSON або збережіть увесь робочий процес як відтворюваний JSON-файл (`Ctrl/Cmd+S`).

## Поради

- **Натисніть на заголовок стовпця** — для сортування, фільтрації, перейменування, зміни типу або дублювання стовпця.
- **Натисніть на комірку** — щоб швидко відфільтрувати за її значенням або замінити його.
- **Shift+клік на заголовках стовпців** дає змогу виділити кілька стовпців і застосувати трансформацію до виділення.
- У діалогах Фільтрація, Derive та Conditional використовується **редактор виразів** з автодоповненням, підсвічуванням синтаксису та підказками для помилок у назвах стовпців і функцій.
- Стрілки переміщують між кроками, коли жоден діалог не відкритий.
- Повний список комбінацій клавіш: [Комбінації клавіш](/uk/docs/shortcuts/).

## Далі

- **Збережіть робочий процес** — `Ctrl/Cmd+S` експортує пайплайн як JSON. Пізніше його можна імпортувати, поділитися ним або версіонувати поряд з даними.
- **Запуск без інтерфейсу** — той самий JSON можна виконати через CLI: `syto run workflow.json --input data.csv`. Корисно для автоматизованих задач або для перевірки, що пайплайн не зламався після змін.
- **Довідник функцій** — функції для тексту, математики, дат, регулярних виразів, JSON та агрегації доступні в бічній панелі. `ExpressionDocs` показує ту саму інформацію контекстно у діалогах Фільтрація / Derive / Conditional під час набору тексту.
- **Експериментальний SQL-рушій** — опціональний рушій DuckDB-WASM доступний у Налаштуваннях для статистики EDA та трансформацій. У разі збою автоматично повертається до JS-рушія.

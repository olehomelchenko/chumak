# Математичні функції

26 функцій доступно

## abs

Повертає абсолютне значення числа

**Параметри:**

- `value` — Числове значення

**Повертає:** Абсолютне значення, або null якщо невалідне

**Приклади:**

```
abs(-5)
abs(-5) -> 5
```

## pow

**Параметри:**

**Повертає:** Основу піднесену до степеня, або null якщо невалідне

**Приклади:**


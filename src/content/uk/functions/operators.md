# Оператори

## Арифметичні

| Оператор | Опис               | Приклад            |
| -------- | ------------------ | ------------------ |
| `+`      | Додавання          | `price + tax`      |
| `-`      | Віднімання         | `revenue - cost`   |
| `*`      | Множення           | `price * quantity` |
| `/`      | Ділення            | `total / count`    |
| `%`      | Остача від ділення | `id % 2`           |

## Порівняння

| Оператор | Опис                | Приклад               |
| -------- | ------------------- | --------------------- |
| `>`      | Більше              | `sales > 1000`        |
| `<`      | Менше               | `age < 18`            |
| `>=`     | Більше або дорівнює | `score >= 90`         |
| `<=`     | Менше або дорівнює  | `price <= 100`        |
| `==`     | Дорівнює            | `status == "active"`  |
| `!=`     | Не дорівнює         | `region != "Unknown"` |

## Логічні

| Оператор | Опис        | Приклад                                     |
| -------- | ----------- | ------------------------------------------- |
| `and`    | Логічне І   | `sales > 1000 and region == "North"`        |
| `or`     | Логічне АБО | `status == "pending" or status == "review"` |
| `not`    | Логічне НЕ  | `not is_deleted`                            |

## Спеціальні

| Оператор | Опис                     | Приклад                        |
| -------- | ------------------------ | ------------------------------ |
| `? :`    | Умовний (тернарний)      | `profit > 0 ? "Gain" : "Loss"` |
| `??`     | Оператор null-об'єднання | `discount ?? 0`                |

## Дивіться також

- **Локальні імена** (`let x = ... in ...`) — дати ім'я проміжному значенню й використати його кілька разів у тому ж виразі. Див. сторінку «Локальні імена (let)».

description: Update docs
---

After implementing or refactoring large chunk of functionality, update docs to reflect changes.

Key documents to update:

- CLAUDE.md - serves as onboarding and instruction set for all agents.
- docs/SPECIFICATION.md - technical details of the project.
- docs/UX-SPECIFICATION.md - user experience and design details of the project.

After the update, the docs should read in "matter of fact" style, there should be no indication that there was some change or update.

Always maintain the docs to be minimally prone to obsolescence - only keep references to the files that are always relevant and are unlikely to change; do not write any exact dates or numbers (number of files, classes, functionality etc).
